# TouchHop

**Touch your screen. Your cursor follows.**

[English](README.md)

TouchHop 是一个原生 macOS 外屏触控定位工具。即使鼠标还在 Mac 内屏，只要触摸已绑定的外屏，光标就会移动到手指所在的位置，并执行对应鼠标操作。

## 当前支持范围

初始版本只支持已经检查过的一种 USB 控制器和报告格式，**不是通用触屏驱动**。

- USB 厂商 / 产品 ID：`0x056A` / `0x8191`，设备自报名称为 `TOUCH`。
- 接口：USB 绝对坐标鼠标，报告编号为 `7`。
- 绑定一个外接显示器，通过显示器 UUID 保存关联。
- 实际验证环境：Apple M4、macOS 27.2、2048 × 2730 外屏；该外屏提供两个鼠标接口。
- 在上述环境中，已确认鼠标从内屏准确跳到外屏的触控位置，包括四角附近和中心；程序重启后可恢复绑定和启用状态。
- 支持点按、双击计数、单指拖动以及四种坐标方向。双击和拖动尚未单独进行现场验收。
- 支持单键与组合键快捷键，默认单独按下并松开右 Command。
- 每次按键切换到下一块屏幕上次离开的位置，并短暂显示放大指针提示。
- 暂不支持多指手势、滚动、手写笔或任意其他 HID 报告格式。

构建目标为 macOS 14.0 及以上；其他系统版本、Intel 硬件和其他控制器尚未经过硬件验证。

## 构建

需要 Apple Xcode Command Line Tools，无需安装第三方依赖。

```sh
git clone https://github.com/chenyongwei/touchhop.git
cd touchhop
./scripts/build.sh
./scripts/test.sh
```

生成的应用位于 `build/TouchHop.app`。脚本默认构建当前电脑的架构，可通过 `TOUCHHOP_ARCH` 指定 `arm64` 或 `x86_64`。交叉编译通过不代表对应硬件已验证。

生成的应用使用临时本地签名，未经 Apple 公证。构建过程不会安装应用或更改系统权限。

## 使用

1. 先退出其他处理这块触屏的工具。
2. 将构建好的 `TouchHop.app` 放入“应用程序”并打开。
3. 选择需要绑定的外屏。
4. 点击“1. 允许鼠标控制”，在系统设置中开启相应权限；部分系统版本将该项称为“设备控制与数据访问”。系统要求解锁时，需要本人完成认证。
5. 点击“2. 打开输入监控设置”，根据系统提示允许输入监控；如系统要求重启应用，请重启。
6. 点击“启用触控定位”，把鼠标留在内屏，再触摸外屏空白位置，检查四角和中心是否准确。方向不对时调整旋转选项。

点击“停用触控定位”或退出应用，就会释放触控接口，恢复系统原来的处理方式。关闭设置窗口不会退出应用，再次打开 TouchHop 即可显示设置窗口。

需要登录启动时，可在“系统设置 → 通用 → 登录项”中添加 TouchHop。已启用的配置会在应用启动、目标外屏在线且权限可用时自动恢复。

开源版 TouchHop 与此前本地原型“外屏触控定位”的应用身份不同，权限和设置独立。启用 TouchHop 前应退出原型；本仓库不会替换现有安装。

## 切屏快捷键与放大指针

默认快捷键为 **右 Command**，单独按下并松开即可。两块屏幕时，每按一次回到另一块屏幕上次离开的位置，再按一次回到这块屏幕先前的位置；更多屏幕时按主屏优先的顺序循环。某块屏幕还没有位置记录时，先定位到中央。

普通鼠标移动和触摸外屏造成的跳转都会更新位置，因此从内屏直接触摸外屏后，也能按快捷键回到内屏先前的位置。每块物理屏幕只在内存中保留最后一个位置，退出应用后清空，不保存鼠标轨迹。屏幕重新排列、改变分辨率或拔插后，按相对位置恢复，并确保鼠标位于目标屏幕内。

在设置窗口的“快捷键切换屏幕”区域，点击显示的按键，即可录入普通单键、左右修饰键或组合键。录入单独的修饰键时，松开后完成设置；Esc 取消。“恢复默认”会恢复右 Command。Esc 和 Caps Lock 不可设置为快捷键。

左右 Command 可以分别识别。单独修饰键只在按下并松开、期间没有参与其他按键或鼠标操作时触发，因此 Command+C、Command+V、Command+点击等操作仍正常使用。若选择字母或空格等普通单键，启用期间会占用该键的无修饰输入；加修饰键的正常用途仍保留。

每次切屏后，都会显示约一秒的放大指针与定位圆环，并跟随鼠标移动，随后自动消退。该提示不拦截点击，也不会永久修改系统的指针大小。可点击“预览指针放大”检查显示效果。

可以单独取消“启用切屏快捷键”，不影响触控定位。快捷键及其启用状态会在重启应用后保留，在其他应用位于前台时也能响应。切屏只移动鼠标，不会执行点击或切换窗口焦点。首次从 0.2 升级时，原默认值 `⌃⌥H` 会迁移为右 Command，其他自定义设置保留。

正在使用实体鼠标拖动时，应先松开按键再切屏。若手指仍在触屏上拖动，TouchHop 会先释放自己按下的鼠标键，再等待该手指离开屏幕，避免光标立即被触控拉回外屏。

组合键使用系统注册快捷键；单键模式通过当前会话的事件监听识别按键编码、左右修饰键状态及用于判断组合操作的鼠标事件。另一个只读的鼠标监听为每块屏幕记住最后一个位置，不修改或拦截鼠标事件。这些监听仅在对应快捷键功能启用期间运行，需要鼠标控制和输入监控权限，不记录输入历史、文字内容或鼠标轨迹。设置窗口的快捷键录入则只处理该应用自身收到的按键。

## 工作方式与隐私

TouchHop 只接管匹配该设备 ID 的 USB 绝对坐标鼠标接口，读取完整触控报告，再把坐标转换为目标外屏的桌面坐标。Mac 内置触控板、其他鼠标、键盘和手写笔接口不在匹配范围内。

程序不连接网络、不上传数据、不记录输入历史或触控轨迹。仅在本机保存屏幕绑定、方向、启用状态与选定的快捷键。目标外屏不可用时，不会把触控改派到内屏。

## 验证与许可

自检包括 71 项报告解析、坐标转换、快捷键保存与迁移、左右修饰键与组合操作识别、屏幕循环、各屏幕位置记忆、布局及分辨率变化、过时事件过滤和放大指针位置检查，不会打开触控设备、安装事件监听、注册全局快捷键、申请权限或发送鼠标事件。GitHub Actions 会自动构建、自检并生成开发版 ZIP；它不验证实际触屏、权限或真实注销登录流程。
